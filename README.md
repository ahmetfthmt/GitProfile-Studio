# GitProfile Studio 🚀

![GitProfile Studio](https://capsule-render.vercel.app/api?type=blur&height=300&color=auto&text=GitProfile%20Studio)

**GitProfile Studio** is a powerful, visual, drag-and-drop builder for creating stunning GitHub Profile READMEs in minutes. No more wrestling with Markdown syntax—just add widgets, customize your details, and export!

## ✨ Features

- **🎨 Visual Canvas:** See exactly what your README will look like as you build it.
- **🖱️ Drag & Drop:** Easily reorder your profile sections using a smooth drag-and-drop interface.
- **📱 Fully Responsive:** Build your profile on the go! Features a dedicated mobile layout with bottom navigation.
- **⚙️ Global Settings:** Enter your GitHub username once, and it automatically populates your stats, streak, and visitor badges.
- **📋 One-Click Export:** Copy the generated Markdown to your clipboard or download it directly as a `README.md` file.

## 🧩 Available Widgets

- **Header:** Add a personalized greeting, subtitle, and an eye-catching dynamic banner.
- **About Me:** Share your story, current projects, and what you're learning.
- **Tech Stack:** Showcase your skills with beautiful, searchable developer icons.
- **GitHub Stats:** Display your GitHub statistics and contribution streaks dynamically.
- **Socials:** Connect with the community by adding links to your GitHub, LinkedIn, Twitter, Website, Instagram, YouTube, Dribbble, and CodePen.
- **Visitors:** Track how many people have viewed your profile with a customizable hit counter.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)

- **Styling:** [Tailwind CSS](https://tailwindcss.com/)

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/gitprofile-studio.git
   cd gitprofile-studio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to start building!

## 💡 How to Use

1. **Add Widgets:** Use the left sidebar (or the "Add" tab on mobile) to add sections to your canvas.
2. **Set Global Username:** Go to the Settings panel and enter your GitHub username to automatically configure stats and visitor badges.
3. **Customize:** Click on any widget in the canvas to open its specific settings and customize the content, colors, and themes.
4. **Reorder:** Drag the handle on the left side (or top right on mobile) of any widget to change its position.
5. **Export:** Click the "Code" tab in the settings panel to view the generated Markdown, then click "Copy" or "Download".
6. **Publish:** Paste the copied Markdown into your GitHub repository's `README.md` file (the repository named after your username).
